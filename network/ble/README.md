# BLE peripheral and GATT check

Two cooperating BLE examples: the peripheral advertises a demonstration service, and the GATT checker uses a second Linux host to exercise it. Read the network tutorial for dependencies, adapter selection, permissions and the tested setup. These examples retain the original source and validation scope.

Tutorial: https://developer.inhand.online/docs/mo-62a/mo-os/network/
