# NPU video inference demo

Video replay scripts, YAML configurations, prepared licensed input clips and existing backend comparison records. Follow the first NPU demo tutorial for the documented image, runtime and device setup. `SOURCE.txt` records each clip's creator, license and edits. Migration preserves those bytes and the previous measurement scope; it does not repeat model or board tests.

Tutorial: https://developer.inhand.online/docs/mo-62a/getting-started/first-npu-demo/
